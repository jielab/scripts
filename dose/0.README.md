# DOSE

UKB 饮食分析与 NHANES 外部验证。入口为 `dose.sh`，实现位于 `f/`。

## 运行

```bash
./dose.sh --help
./dose.sh --list-steps
./dose.sh --dry-run
./dose.sh all --dir-output /mnt/d/analysis/dose
```

完整流程依次执行 `foodwas → ml → score → mechanism → signature → nhanes`，
并生成机制汇总及 UKB/NHANES 比较。也可单独运行这些模块；单模块复用上游结果。
`--steps CSV` 只选择一个模块内的步骤；`-- ARGS...` 将额外参数传给单个显式步骤。

## 输入与配置

- UKB 根目录：`--dir-ukb`，默认 `/mnt/d/data/ukb`。
- NHANES 根目录：`--dir-nhanes`，默认 `/mnt/d/files/diet`（包含 `cdc/`）。
- 字典：`--dir-files`，默认 `/mnt/d/files/diet`。
- 公共 R 工具：`--dir-helper`，默认 `/mnt/d/scripts/0f`。
- 解释器：`--python`、`--rscript`；Python 包清单见 `requirements.txt`。

## 资源与复用

`--jobs` 默认 4，整个步骤进程树默认 RAM 16 GiB、swap 0；正式运行要求用户 systemd 和 cgroup v2。
默认 `--replace FALSE`，输入、代码和输出校验一致时跳过完成步骤；输入一致的中断步骤可续跑。
`.cache` 和 `.checkpoints` 位于分析输出目录，保存跨步骤中间数据与复用记录。
只有确需重算时才使用 `--replace TRUE`；`--skip-basic` 要求已存在基础准备结果。
