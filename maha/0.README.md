# MAHA

入口 `maha.sh` 调度 UKB、NHANES、CHNS 队列分析，并整合已完成结果的图表。
实现位于 `f/MAHA_ukb.R`、`f/MAHA_nhanes.R`、`f/MAHA_chns.R` 和 `f/MAHA_publication.R`。

## 运行

```bash
./maha.sh --help
./maha.sh all --jobs 4 --dir-output /mnt/d/analysis/maha
# 单独运行一个队列：
./maha.sh chns --jobs 2
# 使用已完成结果重新汇总图表：
./maha.sh final
```

无参数与 `all` 都依次执行三个队列；`ukb`、`nhanes`、`chns` 选择单队列。
`--steps CSV` 指定内部分析阶段，此时不自动执行最终图表整合，完成后可运行 `final`。
`--replace-steps CSV` 明确指定需要替换的阶段。

## 输入、依赖与输出

需要 Rscript 及各队列 R 模块所用的依赖。`--rscript FILE` 可指定解释器，
公共辅助代码默认 `/mnt/d/scripts/0f`，输出默认 `/mnt/d/analysis/maha`。
队列辅助文件、启动日志和状态位于输出根目录的 `ukb/`、`nhanes/`、`chns/`。

CHNS 默认读取 `/mnt/d/data/chns`，食物和营养映射位于其 `MAHA_foodcode/`：
`chns_foodcode_map.tsv`、`chns_foodcode_nutrients.tsv`。
基线波次默认 2011，随访截止 2015，最小年龄 40，最少饮食记录天数 2。
原始输入位置和队列内配置以对应 R 模块为准。
地图底图使用 OSM；可通过已有 HTTP(S) 代理或 `--tile-proxy` 配置网络。
