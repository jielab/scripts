02 · ref 能解释到哪一步？

以下逐步取最早日期，始终将 ref 留在比较端。me = min(ICD10, ICD9, OPCS4, SRD, GP)；local_min = min(ICD10, ICD9, SRD, GP, disease-specific death)，两者使用本地疾病定义。reconstructed_ref 使用已公开的 UKB 映射及当前可用记录，作为单独的重建候选；仍须考虑官方映射版本与数据覆盖差异。

如何使用官方来源字段解释差异

房颤：日期字段 131350，来源字段 131351。来源编码：20 / 21 = death；30 / 31 = GP；40 / 41 = hospital；50 / 51 = self-report。末位 0 表示仅该来源，1 表示也见于其他来源。同日冲突时官方优先顺序为 death → GP → hospital → self-report。来源相符只能支持解释，不能证明本地重建与 UKB 内部映射、数据版本完全一致。疾病定义不完全相同、数据版本或覆盖区间不同、日期取整和特殊日期处理，均可能留下未解释差异。

03 · 来源两两一致性

每格：同日率；小字：两来源均有可用日期的人数。点击任一非空格，将下方患者筛选切换到相应的 A、B 来源。缺失日期不进入同日率分母。
