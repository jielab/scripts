### UKB 路径配置

本地 `DIR_UKB` 默认由 `0os.sh` 中的 `DIR_DAT/phe/ukb` 推导；HPC 使用 `DIR_WORK/phe/ukb`。
Shell 读取初始化后的 `DIR_UKB`；Python 使用 `workflow_paths.configured_path("DIR_UKB")`；
R 使用 `0os.R` 的 `os_paths_init()` / `os_path("DIR_UKB")`，实际路径仍由 `0os.sh` 决定。
显式环境变量和命令行参数可覆盖默认值。`phe.sh` 对已经不存在的旧本地 UKB 根目录使用
`os_resolve_ukb_path` 提示迁移到当前 `DIR_UKB`；存在的旧目录和其他自定义目录不被改写。

### 统一路径接口（Shell / Python / R）

所有机器相关的根目录默认值放在 `0os.sh`。项目代码只拼接根目录下的相对路径，
不要再添加磁盘盘符、用户主目录或 HPC 挂载点作为备用默认值。
`OS_PATH_KEYS` 是两种语言适配器读取的统一键列表。

- Shell：先通过当前脚本位置定位并加载共享路径表，随后使用 `$DIR_UKB`、`$DIR_GEN`、`$ANALYSIS_ROOT` 等。
- Python：从 `workflow_paths` 导入 `configured_path`；例如 `configured_path("DIR_GEN", "ukb/37")`。
- R：加载 `0os.R`，调用 `os_paths_init()` 后使用 `os_path("DIR_GEN")` 和 `file.path()`。
- JSON/YAML 默认配置：使用 `${DIR_GEN}`、`${ANALYSIS_ROOT}` 等根目录标记，由配置读取入口展开。
- 程序临时缓存使用 `DIR_RUNTIME_TMP`；它与持久分析目录及兼容变量 `DIR_TMP` 分开。

切换本地/HPC模式时，`_OS_DEFAULT_*` 标记用于重新计算默认值；显式设置的环境变量保留。
本地入口使用 local，集群入口遵循 `--submit`；单独运行 Python/R 时可先设置 `submit=local`。
历史数据清单、运行记录、测试样例中的路径，以及 `/proc`、`/sys`、`/dev` 等系统接口不作为默认目录迁移。
