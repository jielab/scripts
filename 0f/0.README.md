# 0f

共享路径、资源限制、日志与 local/LSF 作业调度。各项目依赖此目录；路径配置见 `0os.sh`。

在本目录查看参数和示例：

```bash
bash img2pdf.sh -h
bash phenotype.sh -h
```

路径优先使用命令行覆盖；共享默认配置位于 `../0f/0os.sh`。
`2test/` 保留回归测试或入口自检依赖，不要作为缓存删除。

## 2026-11-04 路径约定

| 用途 | local | 启明 HPC |
|---|---|---|
| `DIR_DAT`：小文件、软件、分析根 | `/mnt/d` | `/work/sph-huangj` |
| `DIR_BIG` / `DIR_DATA`：大数据根 | `/mnt/f` | `/work/sph-huangj/data` |
| files | `/mnt/d/files` | `/work/sph-huangj/files` |
| software | `/mnt/d/software` | `/work/sph-huangj/software` |
| analysis | `/mnt/d/analysis` | `/work/sph-huangj/analysis` |
| ukb | `/mnt/f/ukb` | `/work/sph-huangj/data/ukb` |
| metag raw | `/mnt/f/metag/raw` | `/work/sph-huangj/data/metag/raw` |
| metag state/results | `/mnt/d/analysis/metag` | `/work/sph-huangj/analysis/metag` |

`SCRIPTS_ROOT` 按当前代码目录定位。`AI_model`、`annot`、`gen`、`gwas`、`LD`、`metag`、`ukb` 均在大数据根。
默认 HPC；本地显式使用 `--submit local`。无需定义 `--dir-tmp`：该参数及 `DIR_TMP`/`DIR_SCRATCH` 仅作为兼容接口保留，不再决定 analysis 或 metag 输入。`--date-scratch` 也不再改变路径。显式项目路径覆盖继续有效。
旧计划不会随默认路径变化自动更新；数据移动完成后另行进行输入、软件、计划和实际作业验收。
