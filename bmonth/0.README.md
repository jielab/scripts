# bmonth v2 — 运行说明与研究定义

模型契约版本 `2026-10-20-exposure-focus`。

本轮以 birth month / birth order 的定义、共同样本、家庭规模比较和周期曲线为核心。默认优先复用已有 PheWAS 面板和现有 CAD/RA 事件／时间列，全部正式输出位于 `/mnt/d/analysis/bmonth/`。缺少自定义 manifest、roster 或覆盖说明不阻断主流程。

表型输入、重点疾病、联合 Cox 和组学设计均在本文说明。

<a id="overview--最短运行路径"></a>

## 最短运行路径

直接运行，不需要填写模块名称：

```bash
./bmonth.sh
```

默认顺序为已有面板和输入检查 → prep → 全结局 PheWAS → 现有 CAD/RA Cox → decomp → 重点 follow-up → final → plot。八项疾病用于重点解释，不代替全扫描。普通运行不会启动表型重建。

| 位置 | 内容 |
|---|---|
| `/mnt/d/analysis/bmonth/phewas/` | 显式 rebuild 的默认写入位置；已有面板优先于输入目录面板 |
| `/mnt/d/analysis/bmonth/raw/` | 分析队列、模型结果、QC 和分析断点 |
| `/mnt/d/analysis/bmonth/fig/` | PNG 图及配套 XLSX |
| `/mnt/d/analysis/bmonth/logs/` | 运行日志与阶段状态 |

普通面板读取顺序为：非空 CLI `--phewas-input` → 非空环境变量 `BMONTH_PHEWAS_INPUT` → 已存在的 `DIR_OUT/phewas/PheWAS.rds` → 已存在的 `DIR_IN/Rdata/PheWAS.rds`。CLI 覆盖环境变量。显式路径缺失时立即报出该路径，即使它恰好等于默认输出路径，也不会回退或重建。两处默认面板均不存在时列出缺失路径及可选 rebuild 命令。

`check`、主流程、`phewas`、`decomp` 和 targeted follow-up 直接使用选中的已有面板；不要求重建源文件、manifest、roster 或新增覆盖证明。没有可信可选来源记录时标记 `existing_panel`。Shell 和直接启动的 R 脚本使用相同顺序，报告实际路径、内容 MD5 和来源状态。直接启动 R 时需设置 `BMONTH_FDIR`、`BMONTH_INDIR`、`BMONTH_OUTDIR`。

`--dir-out` 改变分析输出根目录。只有显式 `roster` / `rebuild` 才进入构建工具；默认写入 `DIR_OUT/phewas`，与普通读取回退无关。沿用已有重建参数语义：在 rebuild 命令上显式传入 `--phewas-input /target/PheWAS.rds` 会选择该目录作为写入目标，文件名必须为 `PheWAS.rds`。普通 `--replace` 仅用于模型断点重算，`rebuild --replace` 才请求重建面板。

```bash
# 新输出目录可直接回退到输入目录已有面板；使用默认 CAD/RA
./bmonth.sh --dir-out /mnt/d/analysis/bmonth-existing
# 也可以显式指定面板
./bmonth.sh check --phewas-input /mnt/d/data/ukb/Rdata/PheWAS.rds
# 关闭全部生存结局，完整核心流程运行至 final / plot
./bmonth.sh --outcomes none --dir-out /mnt/d/analysis/bmonth-none
# 同时运行独立 ProtWAS；mediation 明确跳过
./bmonth.sh --outcomes none --with-omics --dir-out /mnt/d/analysis/bmonth-none-omics
# 可选：明确请求重建，默认目标仍是输出目录
./bmonth.sh rebuild --dir-out /mnt/d/analysis/bmonth-rebuilt
```

`--outcomes none` 不要求 CAD/RA 事件日期：assoc 发布带完整列结构的零行结果；cycle 和 mediation 记录 `skipped_no_outcomes`。Mediation 在读取候选文件、生存和组学输入及模型循环之前跳过，不运行 Xa。PheWAS、targeted birth-order follow-up、独立 ProtWAS 正常运行。Final 按当前结局配置排除上一轮 Cox、cycle 和 mediation 输出，并清除其当前约定图文件；不批量删除旧目录、缓存或其他中间结果。当前启用结局时，空表正常跳过，非空但缺列的生存结果明确报错。

默认流程不自动运行组学或温度；分别使用 `--with-omics`、`--with-temperature` 加入。组学先 screening，诊断后锁定候选 CSV 再 bootstrap。不同协变量配置使用单独输出目录。

实际分析使用现有仓库的 `0f/memory_cap.sh`，保留内存保护。普通运行日志和阶段状态默认位于输出目录 `logs/`，可用 `SCRIPT_LOG_DIR` 指定。合成测试的交付、恢复和运行方式见本文“合成测试交付”。

PheWAS 默认使用 4 个 worker，整个任务仍受 24 GiB RAM／0 GiB swap 限制。中断后直接重新运行 `./bmonth.sh`，或仅续跑 PheWAS：`./bmonth.sh phewas`；输入及模型代码签名兼容的断点会自动复用。不要加 `--replace`，否则会重算断点。可用 `--phewas-cores N` 或 `BMONTH_PHEWAS_CORES` 覆盖默认并发数。

PheWAS 按每批 8 个表型动态分配任务：任一 worker 完成并写入断点后，立即补入下一批，无需等待同轮最慢的模型。每批仍使用独立的单线程 R 子进程，完成后退出释放内存；并发上限、模型拟合方法和最终表型顺序保持不变。异常退出会清理本次调度创建的子进程，已完成的断点保留。

2026-10-21 的调度优化通过 `config/phewas_runtime_compat.tsv` 中精确匹配的两组代码 MD5 复用上一版数值完全相同的模型断点；实际执行代码 MD5 另存于缓存目录的 `runtime_signature.rds`。该映射仅适用于这次已验证的调度修订，后续代码、输入、模型设置或软件版本变化仍会生成不同缓存。已运行的 R 主进程不会自动加载修改；需要在当前任务结束或停止后重新启动，勿对同一输出目录同时启动第二个任务。

| `immune_score_results.csv` | 固定七蛋白和探索性分数 |
| `mediation_screen_audit.csv` | Xa/Mb筛选与模型失败率 |
| `mediation_completion.csv` | running / screen_complete / bootstrap_complete / skipped_no_outcomes |
| `association_status.csv` / `followup_manifest.csv` | assoc/cycle 的本次完成或跳过状态 |
| `mediation_candidate_disposition.csv` | 每个请求候选的实际处置原因 |
| `$SCRIPT_LOG_DIR/stage_status.tsv` | 阶段started/complete/failed和退出码 |

Scalar Cox 在完整病例样本上先保留 nuisance 调整空间，再检查 tested exposure 的独立可估计性；秩检查包含常数项。`age = 50 + border_rank` 等关系返回 `failed_tested_term_not_estimable`，不产生有效 beta/HR/p；常量或冗余 nuisance 的实际移除写入 note。正常模型继续使用未惩罚 Efron Cox。

三个差值比较为 full D2 → common D2、full D2 → full D2+S、common D2+S → common D5+S。第一项允许样本不同；后两项应为相同样本。两端有效时保留描述性 delta；MLE → BR 明确标注估计方法同时改变，不能将全部差值解释为调整贡献。一端失败或 beta 无效时 delta 为 NA。

模型完成并不表示全部拟合有效。未解决eligible检验保留在多重校正分母；失败行原始p保持NA。已看到结果后选择的候选与分数仍为探索性，不能称独立重复。

<a id="overview--保留的研究定义"></a>

## 保留的研究定义

| 暴露 | 定义与对比 |
|---|---|
| `border12` | S=2；第二出生者=1、第一出生者=0 |
| `border1n` | S≥2；最小子女=1、最大子女=0；排除中间子女 |
| `border_rank` | `cnt_older + 1`，自然单位为出生顺序增加一位 |
| `border_relative` | `(rank−1)/(S−1)`；0 为最大子女，1 为最小子女 |
| `bmonth_cos` | **负余弦**：`−cos(2π×month/12)` |
| `bmonth_sin` | `sin(2π×month/12)` |
| 季节对比 | 夏季 vs 冬季；秋季 vs 春季 |

出生顺序排除已收养、无效计数、不可能顺序和独生子女。主规则保留收养状态未知者，新增 `adopted_num==0` 敏感性。全同胞数包含双胞胎，因此它不是母亲孕产次序；双胞胎敏感性必须先核对字段。不同参与者都来自两孩家庭，并不等于实际同胞配对。

D1–D5 继续为：年龄/性别/中心 → 成人教育/TDI → 出生地坐标 → 出生地 TDI 代理 → 迁移距离。`tdi.birth` 仍是当前居住地 TDI 空间表面投射至出生地的代理值，不是出生当年的历史贫困指标。

新增 `age_fractional` 来自已有 `birth_date` 的月中日期代理，不是精确生日。保留线性年龄主模型，并提供同一样本上的年龄样条敏感性。教育、成人社会经济状态、吸烟和迁移可能位于出生后的路径上，系数变化只作条件关联比较。

周期 follow-up 在字段有足够变异时，分别比较加／不加五年出生队列组、加／不加招募年份的同样本模型，不同时塞入年龄、精确出生年和招募年。年龄由招募年反推的近似出生年不用于出生队列敏感性。`Fig_birth_month_cycle` 展示联合模型相对一月的 12 个月效应及 pointwise 区间；`Fig_birth_order_family_size` 展示重点疾病的同样本家庭规模比较，均附 XLSX。

## 已加入的进一步分析

| 研究问题 | 已实现输出 | 解释边界 |
|---|---|---|
| CAD/呼吸疾病偏高、T2D/高血压偏低是否保留 | 八项锁定疾病 × 四种出生顺序；full/common 样本、D1–D5、家庭规模比较 | 当前结果提出的探索性候选 |
| 家庭规模能否解释 birth rank | S=2、3、4、5 精确分层；6+ 仅描述 | pooled 6+ 不冒充固定规模 |
| 样本限制与调整分别改变多少效应 | full D2 vs common D2；common D2 vs common D5；样本 hash | log(OR) 描述性变化，不是中介比例 |
| 问卷引入时间/族群/中心是否影响可用性 | 按年龄、性别、center、招募年、可用 ethnicity 的可用率 | 没有假定缺失随机 |
| birth-month/CAD 是否呈真正周期形状 | cos+sin 联合 Cox、2 df P、协方差、12 月 HR、PH 诊断 | 月区间为 pointwise |
| 大量 rank 蛋白信号是否来自家庭规模 | 同蛋白/同样本 D2 与 D2+S 全扫描、效应差值 | rank、relative 单位不同 |
| NK/T 相关蛋白是否形成一致信号 | 固定七蛋白及探索性平均标准化分数 | 血浆浓度不等于 NK 功能 |
| RA M→Y 失败是否得到解释 | 中心分层 Cox、eventless-centre 数、状态、候选处置、分块保存 | 真实数据仍需检查事件与其他稀疏协变量 |
| 温度调整后周期怎样变化 | 同风险集、稳健联合检验、系数/协方差/月曲线 | 天气异常时空设计与因果识别仍需后续落实 |

八项疾病：冠状动脉粥样硬化 `411.4`、慢性气道阻塞 `496`、肺癌 `165.1`、T2D `250.2`、高血压 `401`、其他周围神经疾病 `351`、听力损失 `389`、胃炎/十二指肠炎 `535`。上/下位 phecode 和四个出生顺序定义都不是独立重复发现。

固定蛋白：`GZMH, FCRL6, KIR2DL2, KLRD1, KIR2DL3, GZMA, GNLY`。缺少任何成员时不改变分数成员，输出原因。集合基于已查看结果和免疫注释提出，必须进一步独立验证。

<a id="overview--可选的后续研究"></a>

## 可选的后续研究

以下扩展不阻断本轮 exposure 分析。现有 CAD/RA Cox 沿用已有有效时间和事件列；完整 incident 重构另行开展。后续设计要点如下：

1. **新发疾病与祖源/招募选择**：先做 CAD、气道阻塞、肺癌、T2D、高血压；使用可靠首次诊断、基线疾病、地区/来源随访、死亡/失访及未知日期处理。再做 UK-born、祖源/PC、年龄/出生队列、问卷开放期和明确未收养者敏感性。
2. **吸烟路径与代谢差异**：同一样本中依次加入吸烟状态、既往吸烟量/戒烟信息，再分别加入 BMI/腰围、糖脂指标和用药；不把所有出生后指标均当成混杂变量。降脂药标志不自动等于 statin。
3. **免疫蛋白来源**：检查批次、采血季节/时间、细胞计数、性别交互、LOD/缺失和原始预处理。分数的性别差异与细胞构成调整预先定义。
4. **真正同胞内/外部验证**：用已验证全同胞关系构建家庭 ID，选择家庭固定效应、条件 logistic 或家族分层 Cox，并报告 discordant families/有效事件数。亲缘连通分量不能直接当兄弟姐妹家庭。
5. **出生月机制**：把平滑年度周期和国家/出生队列对应的入学截止日效应分开；温度优先用同地区同出生时期的天气异常及预指定妊娠窗口。月级生日不能伪装成日级断点设计。

这些扩展仅保留为后续设计方向；不构造不存在的字段，也不要求补齐这些资料才能开展本轮主分析。

<a id="overview--输入完整性与运行前准备"></a>

## 输入完整性与运行前准备

正常安装依赖：`PheWAS`、`brglm2`、`survival`、`data.table`、`dplyr`、`tidyr`、`tibble`、`ggplot2`、`ggrepel`、`digest`、`patchwork`、`writexl`。`terra` 仅用于温度模块。官方映射测试使用实际安装的 PheWAS；完整集成测试另需 `BMONTH_TEST_INTEGRATION=TRUE`。

面板基本检查包括可读取、唯一非空 ID、0/1/NA 结构及病例／对照数量，不把 NA 补成 0。默认记录实际路径和文件 hash；没有可信自定义来源记录时标记 `existing_panel`。可选 manifest 和旁文件全部匹配时才标记 `validated_ICD10_v2`，缺失、过期或格式较旧则不采用其中的验证声明。缺少 manifest 本身不是面板错误的证据。

内部模型缓存仍严格绑定输入、代码、引擎和设置；旧数值错误结果不能恢复为当前结果。模型阶段继续核验 prep 的额外协变量、补充文件内容及显式随访设置。

已确认的 UK ICD10→ICD10CM 转换错误可使用保留的可选构建工具局部修正，工具为 [`../ukb/f/build_phewas_roster.R`](../ukb/f/build_phewas_roster.R) 和 [`../ukb/f/rebuild_phewas.R`](../ukb/f/rebuild_phewas.R)。只有选择重建时才检查它们需要的原始导出文件；已有面板不受这些前置条件约束。无诊断、未映射或个别异常代码不自动取消整个人的其他病例信息。完整风险集重构、外部覆盖证明和全部疾病验证均不属于本轮前置要求。

`check` 默认检查 PheWAS 和暴露输入；单独 `prep` 如缺少可构建的生存结局，会记录为延后处理并继续准备暴露。无参数主流程预检及实际 Cox 模块检查所选结局列和有效事件／时间。现有事件／时间列可直接使用，不要求新增地区随访表；只有需要从日期重建结局时才读取原项目的随访规则。`--outcomes none` 关闭生存结局处理。

已核对字段与编码见 `config/covariate_dictionary.tsv`。技术协变量按真实列名显式指定，缺少扩展变量不阻断疾病主分析。生物学部分先 screening，再对少数明确候选 bootstrap；失败保留状态，结果均按探索性解释。

<a id="overview--面板摘要和缓存"></a>

## 面板摘要和缓存

原始宽面板只在现有隔离打包子进程中完整读取，完成 ID、列名和 0/1/NA 检查，保存病例／对照／缺失计数和 packed metadata。Check、PheWAS、绘图、decomp、targeted follow-up 和温度分解读取摘要或按列读取 packed 数据，NA 保持缺失。每次独立启动重新计算真实输入和可选 sidecar hash，并核验内部格式、源 hash、二进制大小和内容 hash；同一阶段将已确认的 provenance 显式传给绘图，避免逐暴露重复扫描。

内部 packed 格式为 v2。缺少新版摘要或源 hash 的旧 packed metadata 仅在使用时重新打包；不清空全部缓存。队列暴露定义和契约版本未变，输入及设置兼容的既有 cohort 可继续使用。模型缓存仍按实际代码、输入、软件和设置签名校验：涉及修改文件的 PheWAS、ProtWAS、mediation 旧签名将不匹配，下次请求相应阶段时需要重算；同一新版代码和输入的断点仍可续用。Scalar Cox 和 follow-up 在运行相应阶段时重新输出。温度原始提取等无关产物保留，是否复用仍由各模块现有规则判断。不要删除整个 `analysis/bmonth`，也不要改签名强行复用旧结果。

<a id="overview--合成测试交付"></a>

## 合成测试交付

仓库规范要求测试在生产树外。持久测试包为 [`/mnt/d/bmonth-delivery/bmonth-tests-20261020.tar.gz`](/mnt/d/bmonth-delivery/bmonth-tests-20261020.tar.gz)，配套 [`SHA256SUMS`](/mnt/d/bmonth-delivery/SHA256SUMS)。这是本地交付，尚无下载 URL；迁移到新机器时同时复制此包和生产源文件。归档内 `SOURCE_SHA256SUMS` 标识所对应的实际生产源码、配置和上游工具内容，`TEST_PACKAGE.txt` 说明恢复方式及依赖，不依赖原机器的 `/tmp` 残留。

```bash
# 默认从持久归档恢复到新的 /tmp 目录，测试退出时清理恢复目录
./bmonth.sh tests
# 同时运行原有完整 follow-up 和 50 次合成 bootstrap 集成回归
BMONTH_TEST_INTEGRATION=TRUE ./bmonth.sh tests
# 新机器：将归档复制到任意位置后显式传入
BMONTH_TEST_ARCHIVE=/path/to/bmonth-tests-20261020.tar.gz ./bmonth.sh tests
# 也可手动恢复，测试始终接收当前生产 f/ 路径
mkdir -p /tmp/bmonth-tests-restored
tar -xzf /mnt/d/bmonth-delivery/bmonth-tests-20261020.tar.gz -C /tmp/bmonth-tests-restored
BMONTH_TEST_DIR=/tmp/bmonth-tests-restored ./bmonth.sh tests
# 从 scripts 根目录核对交付时源文件版本
(cd /mnt/d/scripts && sha256sum -c /tmp/bmonth-tests-restored/SOURCE_SHA256SUMS)
```

入口执行 R 语法检查、Shell 调度测试和合成回归。保留稳健 logistic 引擎、共同样本、四个出生顺序定义、ICD10 映射、组学和图表回归，补充默认面板发现、隔离摘要与内容变更、Scalar Cox 仿射共线、家庭规模 MLE→BR 和 none 流程测试。None 集成使用当前生产 R 源文件、真实脚本调度和合成输入；仅隔离无关的控制台／系统资源包装器，不修改测试副本中的算法。测试包需要项目及现有 `0f/plotting.R` 和相关 `ukb/f/` 文件、Python 3、tar 及前述 R 依赖，无需 UKB 私有数据。测试日志和合成结果留在 `/tmp`，这些检查不代表 UKB 全量验证。
