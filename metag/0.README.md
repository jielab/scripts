# metag

CPU 宏基因组并行建库与 FASTQ 分类。顺序为 `1.library.sh` → `2.kraken.sh`；`3.compare.sh` 可选。资源配置见 `hpc.yml`；暂停建库可从原生检查点恢复，申请时限不代表完成时间。

在本目录查看参数和示例：

```bash
bash 1.library.sh -h
bash 2.kraken.sh -h
bash 3.compare.sh -h
bash install.sh -h
bash metag.sh -h
```

路径优先使用命令行覆盖；共享默认配置位于 `../0f/0os.sh`。
`2test/` 保留回归测试或入口自检依赖，不要作为缓存删除。
