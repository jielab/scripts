# allele3 FINAL

版本：6.0.1。当前四个入口是 `1.pca3D.sh`、`2.herv.sh`、`3.scan.sh`、`allele3.sh`。路径配置保存在 `allele3.env`；命令行参数优先。日常代码目录只保留这一份 README。

本轮完成代码修改和小型合成验证。依照用户要求，不执行真实 PCA 时间分析、RepeatMasker、gnomAD 全扫描或 UKB 全队列投影；这些分析由用户运行。代码实现不等于取得新的生物学结论。

## 2. 当前运行方式

```bash
cd /mnt/d/scripts/allele3
conda activate allele3-evolution
./1.pca3D.sh --out /mnt/f/gen/ancient/allele3/pca3d/
./2.herv.sh --out /mnt/f/gen/1kg/38/herv/HG00096
./3.scan.sh --out /mnt/f/annot/gnomad/allele3
./allele3.sh --preflight
./allele3.sh --out /mnt/d/analysis/allele3
```

- `1.pca3D.sh --out DIR` 默认 `run --replace TRUE`：从原始 PGEN、HQ variants 和补充表重新生成 metadata、拟合 PCA、投影并绘图。只有显式 `render` 才读取已有坐标。
- `2.herv.sh` 默认 `--replace TRUE`：重新构建个人序列并执行 RepeatMasker，默认目录按 `--dat`（或 `--gen`）、`--build`、`--sample` 生成；默认值为 `1kg`、`38`、`HG00096`。输入 VCF/PGEN 和 FASTA 随数据集/版本同步切换，`--out` 可覆盖输出。
- `3.scan.sh` 默认 `run --replace TRUE`：重新执行完整扫描，必须明确给出 `--out` 或 `--store`，可直接使用 `/mnt/f/annot/gnomad/allele3`；新 shards 和 annotations 都在该目录生成。`allele3-OLD` 保留。
- `allele3.sh` 主分析读取完成的 scan 和 PCA 坐标，默认结果在 `/mnt/d/analysis/allele3/final/herv_focus_20261028`。`primary` 使用 `--scan-dir` 指定的当前 counters，不自动切换到 `SCAN-DIR-OLD`，也不依赖固定历史摘要。已经恢复完整旧库时，无须为新增古人类队列重建 gnomAD 扫描库。

`./allele3.sh --out /mnt/d/analysis/allele3` 自动使用其下的 `final/herv_focus_20261028/`，阶段结果写入该目录的 `primary/`、`archaic/`、`spatial/`、`time/` 等子目录，完整日志位于 `logs/`。`--dir-analysis-root` 指定自定义根目录时同样处理；显式指定其他独立输出目录则按原样使用。

三个重新计算入口遇到已有输出时，将旧产品保存在同级 `.previous_时间戳` 目录，再生成新产品；运行中的目录受锁保护。最好每次测试使用不同的新输出目录。需要恢复断点或读取已完成缓存时明确选择：

```bash
./2.herv.sh --replace FALSE
./2.herv.sh --replace FALSE --no-reuse --out /独立的未完成个人运行目录
./3.scan.sh verify
./3.scan.sh run --replace FALSE --out /独立的未完成扫描目录
```

HERV 复用模式的 `variants/`、`chunks/` 可为指向 F 盘完成缓存的链接，不能作为可写副本。`3.scan.sh plan/adopt/verify` 仍提供旧结果盘点、复制及验证；原 `run.json`、完成标记和科学结果保留，迁移路径通过 sidecar 解析。

HERV 启动时先用短序列试运行 RepeatMasker，再开始耗时的染色体准备。数据库路径或工具异常会提前退出，并提供 `OUT/logs/repeatmasker_preflight_*.log`。默认屏幕每 300 秒显示一次进度摘要，阶段结束立即提示；失败只显示最多三条关键信息，完整 JSON、工具输出和错误仍保存在日志中。可用 `--screen-log-interval N` 调整间隔，或 `--verbose-screen` 查看全部输出。已经完成染色体准备但注释失败时，使用 `--replace FALSE` 继续当前运行。

四入口可用 `--dry-run` 检查命令；不会启动分析。`--help` 不依赖有效本机配置；显式指定不存在的配置会在实际执行时报错。

## 4. 新增 PCA 时间动态分析

```bash
./1.pca3D.sh trajectory-plan
./1.pca3D.sh trajectory
```

两者读取同一冻结坐标和 metadata，不读基因组矩阵、不拟合新 PCA。默认输出 `/mnt/d/analysis/allele3/pca3d/temporal`。`trajectory-plan` 只生成样本/共同支持审计；`trajectory` 生成统计表和 F1–F5 PNG/PDF。

默认主分析 PC1/PC2，可用时补充 5/10 PC；显式 `--pcs K` 必须有连续 PC1..K AVG。SUM-only、混用 raw eigenvector 与 AVG、重复 IID、非有限坐标和混合基底不能用于调整。自定义坐标缺少可信基底来源时仅允许明确标记的描述性结果。

正式样本要求 include=1、unrelated=1、明确 cohort/地区/日期、成功匹配坐标；重复生物学个体、未知关系及缺资料单列排除审计。原 metadata 不被新补充表覆盖；仅补充缺字段。现代独立比较，古代窗口包含 0 和 10000 BP，最后一格包含右端点。

三类估计分别输出：

- raw：每格实际纳入样本的均值、分布和 N。
- fixed-composition：固定地区或地区内技术/来源权重；任一正权重层缺支持则为 NA，不逐格重新归一，不跨缺格连线。
- adjusted：地区内及总体年龄线性模型，按可用字段加入地区、来源/技术、coverage；PC 为响应时不把同一个 PC 再当协变量。保存完整样本名单、设计列、秩、条件数、VIF、HC3 区间及统一 BH 校正。不可识别输出原因。

固定 PC 缩放用于质心位移、离散度及与地区现代参考的距离；没有该地区现代参考则为 NA。PC 离散度不是核苷酸多样性。均值区间为固定 seed 的个体 bootstrap，条件于当前样本和冻结坐标；来源类别不冒充独立研究 cluster。

默认 1000 年格、最小 N=20、bootstrap=500，附带 500/2000 年及半格边界敏感性；还输出高 coverage、shotgun 标签、训练/投影身份及相关性审计。只有点日期时标记 `date_uncertainty=not_provided`；不制造 ±500 年误差。有真实日期分布时可传入：

```text
--date-distributions /path/dates.json --date-draws 100
{"sample_id": {"ages_bp": [1200, 1300], "probabilities": [0.4, 0.6]}}
```

真实区间 `age_lower_bp/age_upper_bp` 的均匀抽样必须显式 `--date-interval-uniform`，标为假设性敏感性。现代不进入古代日期抽样和连续年龄斜率。缺失 mask 重投影、dosage/hardcall 对照、独立 read 验证、新基底敏感性需额外数据，记录为未执行。

主要输出：`trajectory_plan.json`、`sample_audit.tsv.gz`、`sample_composition.tsv`、`support_audit.tsv`、`reference_weights.tsv`、`pc_scaling.tsv`、`temporal_centroids.tsv`、`temporal_dispersion.tsv`、`temporal_contrasts.tsv`、`standardized_trajectories.tsv`、`temporal_models.tsv`、`sensitivity_summary.tsv`、`date_sensitivity.tsv.gz`、`figures/` 及逐图底表、`manifest.json`、`report.html`。

大样本 HTML 用循环计算范围，避免对 487,409 个值展开调用 Math.min/max；显示最多 20,000 个固定 seed 分层点，同时保留全量统计和完整坐标。显示抽样不参与主统计。

## 5. 基于当前 counters 的 gnomAD 主结果

`primary` 从当前完成扫描的 global/exposure counters 重新计算 ERV1、ERVK 在 AC5/AC10 下的 O、E、O/E 和区间，输出 `primary/primary_enrichment.tsv` 及对应 manifest。重复主行、计数或比值不一致等错误会报错；缺失或缺乏训练支持的结果保留 NA。显式选择阶段时只运行所选阶段，不强制先运行 `primary`。

输入 build、染色体与 QC 条件以该次 `run.json` 为准，使用 population_mode=all。默认 eligible 分母是 PASS、至少一个 ALT AC≥1、AN≥100 的 SNV，沿用该次 strict/exclude_combined 排除条件。AC 阈值 t=5/10 下至少两个不同 ALT 各达到 AC≥t 才算 multi-ALT；不保证 REF 也在样本中出现。

家族区域是 RepeatMasker 实际 aligned blocks 的 union，不填 joined gap，不加外侧 flank；目标限于 EUR LD partition 覆盖。EUR 指 LD 分区来源，不是只用 EUR 基因型。期望按 trinucleotide context × primary ALT AF × AN 分层，对每条染色体采用其余染色体的 strict eligible SNV 背景，包括 ERV/LTR：

```text
p[-c,s] = (M[-c,s] + 0.5) / (N[-c,s] + 1)
E = sum(N[target,c,s] * p[-c,s])
O/E = sum(O) / sum(E)
富集百分比 = (O/E - 1) * 100%
```

保留原不支持分层规则，默认进行 2000 次 EUR LD-block bootstrap。O/E=2 是增加 100%，不是增加 200%。该结果不来自 HG00096 RepeatMasker，也不来自 3202 人 burden；common-support、空间和古代分析的估计对象仍需分别说明。

### 新 1KG / UKB 古人类片段队列

`archaic` 从 GU 的原始完成结果开始，处理链为：原始每人片段 → 同人/同参考重叠合并 → 携带人数与比例区间 → 必要时 GRCh37→38 liftOver → 按区间并集查询原 gnomAD VCF → 原扫描 QC/暴露计数 → LOCO O/E、EUR LD-block bootstrap、FDR → 综合报告。无需手工生成 BED，也不向完成的 scan 库写入新标签。

```bash
# 先检查新队列的 22 条常染色体、完成状态、样本名单和依赖。
./allele3.sh archaic --archaic-datasets ukb012,ukb013 --preflight
# 只计算所选队列并更新报告；不自动插入 primary。
./allele3.sh --stages archaic,report --archaic-datasets ukb012,ukb013
# 自动发现所有完整的 1kg、ukbNNN；支持带引号的名称通配符。
./allele3.sh --stages archaic,report --archaic-datasets auto
```

默认 `--archaic-root /mnt/f/analysis/gu`，识别 `ibdmix` 和 `ibdmix-GPU`。同一队列两种模块同时存在时必须用 `--archaic-module` 指定，避免重复分析。支持 `chrN/final/all_archaic_refs*.segments.tsv.gz` 和旧发布格式 `chrN/ibdmix.raw.tar.gz`；旧归档只读取开头的 `.complete` 元信息做预检，实际计算流式读取 final 片段，不解包归档。每个染色体需要 `samples/ALL.txt` 和 `run.meta.tsv`；同队列的样本集合、build、参考列表、原始阈值必须一致。分母包括没有片段的人，不能以片段中出现的人数代替。默认 LOD≥4、长度≥50 kb、携带比例阈值 0.01/0.05/0.10/0.20；不能把过滤阈值降低到原始已完成 GU 结果的阈值以下。

`auto` 把不完整或不一致的队列记入 `archaic/datasets.tsv`，只计算就绪队列；显式选择未完成队列则报错。没有任何就绪队列时不会宣称计算成功。数据集分别计算，不合并可能重叠的 UKB 样本。

大型中间结果默认在 `SCAN-DIR-archaic/DATASET`，可用 `--archaic-cache` 改位置；综合结果位于分析输出的 `archaic/archaic_enrichment.tsv`、`datasets.tsv`、PNG/PDF 和 `manifest.json`。独立队列缓存校验原始文件、参数、相关代码及输出清单；增加新队列时复用通过校验的旧队列。失败会使本轮结果无效，之前的文件保存在 history 中。输入及缓存使用 size/mtime 检查，不对大型原始文件新增全文件哈希。

常染色体富集使用全常染色体的原始 eligible SNV 背景，保留原 strict masks 和固定 AC 分母；不会只用 multi-ALT 缓存凑分母。新增片段覆盖范围较广时，索引 VCF 查询仍可能耗时很长。古人类原始定义沿用 `min-training-sites=1`（`--archaic-min-training-sites`）和 seed 20261024（`--archaic-seed`），不混用 `summary` 的共同支持筛选。汇总 FDR 在本轮所选古人类队列内、按 AC 阈值/敏感性分组重算；所选队列变化会改变 FDR。原历史表保持不变。

默认 `--archaic-chromosomes auto` 还会分别发现并分析完成的 X、Y；缺少 GU 或原 modern 染色体输入时，在 `datasets.tsv` 记录原因。显式 `--archaic-chromosomes X,Y` 可单独分析两条性染色体，`autosomes,X,Y` 要求三类输入，`autosomes` 仅计算常染色体。直接运行 `f/herv_archaic.py` 使用对应的 `--chromosomes` 参数。X/Y 的缓存独立为 `DATASET.chrX`、`DATASET.chrY`，各自使用 `chrX/samples/ALL.txt`、`chrY/samples/ALL.txt` 的实际分析人群（含零片段者），不要求它们与常染色体样本集合相同。样本名单须反映该染色体实际接受分析的人，不能从片段阳性者反推；携带比例不解释为男性频率或等位基因频率。

X/Y 保留原始 VCF AC/AN，不假设 `AN=2×人数`。分别在同一染色体内按 context、AF-bin、AN-bin 和敏感性匹配，以每个标签覆盖范围之外的 eligible loci 为对照，使用 `(control_multi+0.5)/(control_sites+1)` 计算描述性 O/E。没有 EUR LD 分区的位点也保留，分层明细见独立缓存的 `sex_chromosome_strata.tsv.gz`；结果进入总表，状态为 `descriptive_same_chromosome`。任何暴露分层的对照不足时 O/E 为 NA。X/Y 不进入常染色体 LOCO 训练，也不进入其 FDR。

当前 global counters 没有 PAR/非 PAR 或性别维度，因此 X/Y 的这项输出是描述性比较，P、CI、FDR 均为 NA；不能据此宣称显著富集或与常染色体的显著差异。进行正式 X/Y 推断需另行建立 PAR/非 PAR、性别/倍性及染色体适用的依赖结构模型。这里不把 Y 的物理区间当作相互独立的 LD block。

`alleles/time` 使用完整 catalog，默认 `allele_max_sites=0`；500/family 只限制现代直接 GT 验证面板。PGEN 按位点分块，按实际 A/C/G/T 碱基及 PVAR 的 allele index 读取计数；REF/ALT 交换时不能用 `2 − 单个 ALT dosage` 代替目标碱基。来源不明的二等位或 split 行若需计数其 REF，结果为 NA；未编码第三 ALT 也为 NA，不用 split 记录相加宣称恢复古代三等位基因型。直接 GT 验证中，同一相位集内同相位的不同 ALT 冲突被排除，合法反相位保留；已定相但无 PS 的 GT 按 VCF 的隐式相位集检查。

time 的默认 PC 调整要求 10 个完整、同基底的已验证 AVG；缺失时保留 raw 曲线，调整模型明确 unavailable。只有显式 `--time-pcs 0` 才运行标注为未控制遗传结构的模型。逐 ALT 的调整不改变原 pooled family 曲线的含义；新增地区内和固定地区/技术构成曲线单独保存。主线的 `--bootstrap`、`--seed` 会明确传给 time，采用调用者指定的次数和随机种子。

联合指标先冻结有共同支持的 case-control 匹配集 P；同一人的 case 和全部对应 controls 均可测才计入该 pair。保存固定权重、个人有效集合、callability、case/control 均值和差值。个人不完整面板仅称 `observed_pair_conditional`；正式个人模型使用严格完整面板。跨期先计算 pair×地区×时间的同人差，再按固定 pair 权重汇总，缺任一 pair 则为 NA。

新增可测性漏斗覆盖 catalog ALT、GRCh37 映射、精确 PVAR、HQ、各 epoch、固定面板和实际模型；输出个人审计、缺失与年龄/PC/来源的关系、固定地区轨迹、整染色体 bootstrap/leave-chromosome 敏感性。非重叠位点为主分析，重叠或仅边界位点单列。F6 和 `joint_*.tsv[.gz]`、`joint_manifest.json` 进入有效报告。这些是固定可测面板的配对统计，不是古代全基因组富集估计或选择系数。

空间 head/body/tail 沿链方向及实际 aligned bases 定义，short/ambiguous 单列；分区 O、E 回加到 total，O/E 按 E 加权，gap/flank 不混入。`spatial`、`candidates` 和 `alleles` 共用空间分区实现与 `--end-bp`、`--body-bins`，参数记入结果身份，避免候选标签与空间分析不一致。`primary_spatial_*` 使用主结果的 LOCO 模型及 EUR LD 分区对账；common-support 空间结果另行保留。发现/验证染色体规则保留；joined head 不等于 TSS。spatial/windows 缺失的精确分母仍需局部 indexed VCF 读取，不是全基因组重扫。

PCA marker 与 HERV 目标只做重叠审计，不把全 catalog 自动加 ±1 Mb 排除后重训。selection 仅精确连接已发表 REF/ALT，默认 raw_only；同源古代数据不称独立复制。LD 关联不等于因果。未提供 read 证据时不能把插补/shotgun 标签当成独立 WGS 证明。

## 7. 状态、验证和保留规则

新派生阶段采用目录锁、独立 staging 和有效输出清单。重复成功时旧结果保存于同级隐藏 `.目录.history/`；本轮失败即将当前 manifest 标成 failed，旧文件保留但不能作为新证据进入 report-only。running、未知状态、修改过的输出或缺失清单不视为成功。

常规输入和输出采用 size/mtime 校验。关键 metadata、冻结 PCA 凭据及外部投影的成对分数使用完整 SHA256 身份检查；旧工具已有签名继续兼容。size/mtime 不等于密码学完整性验证。完整 gnomAD 或个人 HERV 原始输出的重新计算仍可能耗时很长。

```bash
./install.sh --check --stage trajectory
./install.sh --check --stage project
./install.sh --check --stage all
```

检查记录实际 Python、包及工具版本，RepeatMasker 沿用个人入口的环境发现方式。正式任务继续使用 systemd/cgroup 整个进程树限制，默认 RAM=16 GiB、swap=0。

本次修复的回归测试位于 `tests/`，覆盖当前 primary 估计与空间对账、输入目录保护、split 相位、实际碱基计数、PCA 投影凭据及参数传递。合成测试不替代真实数据分析。

`build-db/split` 属于 metag。grid 的四个编号入口、metag 的两个编号入口仅补充 usage 永久路径，执行代码不变；grid PRSformer 当前没有另配 F 盘模型缓存，不能把 D 盘输出误说成已永久保存。
