## 发现与修正

- 原包 README 引用的 PROJECT_PROPOSAL.md、DESIGN.md、VALIDATION.md 均未随包提供。已明确这一事实；不把旧版设计文档当作 v3 设计，也不将原发布者的验证声明当作本地验证。

- 中断阶段没有 DONE 时，原实现可能将遗留模型/表格纳入下次完成清单；现在先清理这个未完成阶段，再重做。已用人为遗留文件复现并验证清理。
- 兼容本机 `met.lst` 的 data_field/met_name 表头，同时保留无表头支持。
- 图表 Excel 中的原始参与者 ID 替换为各工作簿一致的示例编号；人级内部分析结果保留原 ID。
- 对旧版结果执行新版 final 时明确说明版本不兼容；不会把旧缓存误当 v3。
- 缺少稳定性输出时不再一概声称未找到多状态解，因为用户也可能禁用了重复试验。

## 使用差异与验证边界

默认 run-name 改为 `v3`，完整分析默认输出 `/mnt/d/analysis/panome/cvd_cad/prot/v3/`；图表在其 `publication/` 中，为三组 PNG/PDF/XLSX，**不是旧版八组图**。旧 `main` 结果保留；新版不导入其模型和缓存。新版目前只接受 prot、met 或 prot,met（分别分析），不是任意组学或多视图联合模型。

未完成真实全量 UKB 训练、GPU 测试、外部验证或本地 PGS 端到端测试。合成数据仅两轮训练，用于软件验收，不能代表模型性能。大于 5,000 个训练样本时使用的近似邻居分支未在本次验收中运行。当前修正不消除原版本的科研限制：完整代码/路径/依赖变动会使训练缓存失效；final 可从已完成 v3 结果独立重绘。论文工作簿采用示例编号不等于分子特征已经不可再识别，仍应按数据使用规范管理。
