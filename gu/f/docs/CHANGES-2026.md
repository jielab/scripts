# GU FINAL 2026 整理说明

本版按重新安装代码、重新计算全部结果设计。代码基于 `jielab/scripts` 提交 `9c04bfd38ee703f6eeb259955e08ce16c29cec7e`，包含之前已验证的算法修复，本次进一步收紧公开接口和结果契约。

## 本次实际修改

| 部分 | 当前行为 |
| --- | --- |
| IBDmix 入口 | 唯一模块 `ibdmix`，通过 `--GPU TRUE/FALSE` 选择后端，共用结果路径 |
| 默认参考 | 五个当前参考在 CLI、准备、安装检查、HPC 计划中保持一致 |

| 结果模型 | 仅保留 PhyML、IBDmix、TRACE 三种方法，SQLite user_version=2026；读取端不补列、不迁移旧数据库 |
| 汇总 | 以实际完成单元、实际参考和保存的调用 roster 为依据；保留零检出，未检测为 missing |

| 新运行续跑 | 完整当前 provenance、输入身份及输出校验匹配才复用；删除从历史日志、旧目录、不同参考集合自动认领的路径 |
| 有效报告 | 保留当前 PhyML 报告和共享数学助手，删除已经没有产物写端的独立报告链 |
| 配置 | `f/runtime.env` 自动加载本机或 HPC 默认路径，显式环境变量可覆盖 |
| ARG 样本 | 显式样本表优先用于 ancestry，避免掉入无关的默认人群表 |
| HPC | LSF CPU arrays，批次/染色体独立结果根，冻结输入与代码（含配置），完成后统一汇总 |

## 保留的科学修复和验证范围

原生准备与 CUDA 分段算法保持上游语义；chrX 过滤、区间边界、缺失 GT、重复位点、参考文件的准确染色体匹配和结果完整性继续受测试。男性 X 仍使用伪二倍体编码和二倍体似然，未声称完成单倍体统计校准。

PhyML 保留 lead 等位基因匹配、序列与重复坐标检查、LD 使用样本、树完成校验和超时记录。ARG/TRACE 保留多常染色体联合拟合、男性 X 独立样本映射、地图验证、输入身份检查和 inference 文件保护。

本次不调整既有阈值来改变 X/常染色体比例。汇总按明确单位和分母解释数据；完整真实数据重跑后的生物学结论需要以实际结果为准。

测试使用合成基因型与合成 ARG，官方算法对照使用真实上游源码。GPU 算法对照为 CUDA 源码的主机编译，不代表设备实测。HPC 测试为模拟 LSF，不代表已经提交到集群。R 做语法解析，完整 Shiny 交互和完整环境安装尚未执行。详见 `2test/README.md` 和顶层 `RELEASE.json`。
