哪些位置在两个队列中重复出现？

比较相应参考的版本（Altai.2013 ↔ Altai，Denisova.2013 ↔ Denisova3）。选择不同的人群、阈值和染色体，可查看双向检出率、Jaccard 和频率秩相关。YGB 的祖源标签未上传；EUR 仅限制 1KG 一侧。

控制样本量后，差异还有多大？

从 YGB 均匀、不放回抽取与 1KG EUR 相同人数。利用超几何分布精确计算每个窗口被 ≥5 人检出的概率，累加得到期望交集、并集及两者之比。这个比较控制了样本量，仍保留祖源和流程差异。

如何定义并使用一个 ASV

  1. 以 GRCh37 BED0 半开坐标处理导出；保留长度 ≥50 kb、母片段 SLOD ≥4 的记录。剔除触及 UCSC hg19 ≥100 kb assembly gap 的整条片段与窗口。X 限定中央非 PAR。共同可检测区域配置为 @@MASK@@
  2. 从坐标 0 开始用固定 @@W@@ bp 完整窗口作为标记。一个参考的一条片段须覆盖窗口 ≥80%。同一人、同一区域、同一参考只计一次。YGB 中 N 需要三份 N 参考中至少两份支持且两份 D 参考均无匹配；D 需要两份 D 均支持且三份 N 参考均无匹配。它们量化参考偏好，尚不能给出真实供体、基因流方向或拷贝数。
  3. 在所选 YGB 批次合计 ≥@@MIN@@ 个不同携带者可入目录。按从左到右的首个合格窗口为哨兵，连续同类窗口与该哨兵的携带者集合 Jaccard ≥0.80 才并入。块末端 block_end0 用于显示；暴露只取哨兵。相邻标签仍可能高度相关。同一个生物学单倍型可能贡献多个标签；合并批次重建目录会改变代表位点选择。
  4. 矩阵按人编码：1＝满足谱系规则；0＝本谱系所有参考均无达到覆盖阈值的片段；NA＝单参考或跨谱系证据、或此人未参加该染色体检测。这个 0 描述流程的阴性。负数 ID 标记不参与计数或表型连接。GitHub 缺少个体级 callable mask；正式关联须在可检样本内并考虑缺失。性别、祖源、近亲和每批频率估计均影响解释。
  5. 先看独立队列定位与 LOD6 的持续性，再核查相同祖源、相同过滤条件及基因型；针对少量候选用标签 SNP、分相单倍型或 TRACE 正交复核。PheWAS 建议先锁定 catalogue，再按祖源和批次处理关联，chrX 单列，对稀有结局核查病例携带人数。只有提供独立表型与协变量后才能计算效应值。

输出和输入审计

loci.tsv.gz 提供代表位点与证据；windows.tsv.gz 保留全部窗口，须读取 eligible；batch_windows.tsv.gz 保留分批计数；genotypes/ 的位压缩数组可经 gu.paper.sh export --matrix 导出 HDF5 的 ASV × IID 矩阵（1、0、−1）。audit.tsv 可按参考和染色体检查缺口、最长片段与输入规模。可发表图在 figures/，提供 PDF、SVG、PNG。
