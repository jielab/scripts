## 可直接复制的完整重跑命令

```bash
cd /mnt/d/scripts/le8
./le8.sh --Y cvd_cad --biom prot,met --preflight && \
./le8.sh --Y cvd_cad --biom prot,met --replace TRUE
```

第一条分析命令仅预检；确认成功后执行下一条。`prot,met` 一次覆盖两层，默认顺序为 C1 统计、CUDA ABM、C2、C3、C4、C5。`--replace TRUE` 强制重拟合，包括 MR 已验证任务；不会只因旧成功标记而跳过。预处理/LD 缓存不改变统计任务的重新执行。

全部分析成功后生成汇总并启动查看器：

```bash
./le8.sh final --Y cvd_cad --biom prot,met
./le8.sh shiny --Y cvd_cad --biom prot,met --no-reindex
```

以后意外中断时，去掉 `--replace TRUE` 可恢复有效检查点；再次带该参数会重新拟合。正式结果位于 `/mnt/d/analysis/le8/cvd_cad/{prot,met}/`。运行日志及工作区位于 `/tmp`，日志会显示实际路径。
