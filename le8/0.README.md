# le8

LE8 疾病与组学分析。`le8.sh` 默认运行 C1–C5；C1 默认比较 glmnet、LightGBM、abm_count 和单独标注的 abm_deep 敏感性模型。支持 local/HPC，先用 `--plan-only` 预览；计划须在实际运行机器生成。计数支持不足时拒绝，完整人群评价保留先验回退。

在本目录查看参数和示例：

```bash
bash install.sh -h
bash le8.sh -h
```

路径优先使用命令行覆盖；共享默认配置位于 `../0f/0os.sh`。
`2test/` 保留回归测试或入口自检依赖，不要作为缓存删除。

## 每个 trait × biom 一个 job

```bash
./le8.sh --Y cvd_cad --biom prot,met --plan-only
./le8.sh --Y cvd_cad --biom prot,met
```

每个新计划的 `commands/` 只生成 `cvd_cad.prot.cmd` 和 `cvd_cad.met.cmd`，
正式运行只提交两个 job。每个 job 在同一个 allocation 内依次运行 C1 各阶段、
C2、C3、C4 各阶段和 C5。最后完成科学分析的 job 执行汇总及显式请求的报告，
不额外提交汇总 job。若所选阶段需要 GPU，整个 job 使用 GPU 队列及相应资源。
内部阶段不会自动补跑已经失败的上游；独立分析继续，依赖缺失结果的具体部分记录 unavailable。

病例不足按具体模型、分层、时间窗或基因记录 skip/unavailable；保留原统计门槛，
不再用预测模型的病例门槛排除关联分析、整个 biom 或 trait。
`--min-cases-with-biom` 仅用于预测方法。旧的整组 exclusion 日志不再阻止运行。
原有的稀少病例拟合保护继续生效；C4 的有效冻结 panel 和 LE8 重构不依赖疾病风险拟合成功。
没有有限疾病 P 值时不生成疾病排序 panel；本次不可用的模型也不会被历史拟合或可靠性汇总替代。

`logs/scopes/<trait>.<biom>.json` 记录各阶段退出码；具体跳过原因保存在各模块的
status、support、fit_diagnostics 等表中。程序错误会继续尝试后续阶段，最终 job 仍返回失败。
`--resume-plan` 保留原计划结构；要使用新粒度，重新运行上述命令生成新计划。

HPC 默认 GPU 队列为 `2v100-32-sc`（2026-11-05 经 queueinfo 核对），可用
`--gpu-queue` 覆盖。abm_count 使用 CPU；abm_deep 在 HPC 默认使用所申请的 GPU。
默认三个 trait × 两种 biom 只生成六个 `.cmd`，每个依次执行全部 C1–C5。

疾病 GWAS 尚未生成时，C2 的 MR/反向 MR/MR-link-2/DANDELION 及 C3 共定位记录
`unavailable_genetic_inputs`；C2 的个体 PGS 分解仍独立尝试，C1/C4/C5 继续。
部分完成状态不会被当作完整遗传分析缓存；补齐 GWAS/QTL 后再次运行会重新检查。
细胞图谱和已发表 CIGMA 默认读取 `${DIR_ANNOT}/le8/cellage/atlas.csv` 和
`${DIR_ANNOT}/le8/cigma/chen2026/cigma.results.csv`。缺少可选 PGS/h2 仅影响对应部分。

### 方法版本与结论边界

- 审查所述旧默认（7490bfe）为 glmnet、lightgbm、abm_case_preserving、
  abm_profile、abm_prevalent；2026-11-02 默认（4a4420a；配置版本
  `LE8-C1-primary-2026-11-02-v1`）为 glmnet、lightgbm、abm_count。
  本地 AF / MI、prot / met 的 FINAL 索引仍为旧方法；不能改名或作为新 abm_count 的验证。
- abm_count 是分子 PCA 邻域的 IPCW 局部事件率、family ESS 收缩与固定支持阈值/
  abstention，keep_fraction=1，无 query regression head 或概率校准器。
  旧 donor-pruning / fitted-head 方法作为显式敏感性选项保留。
- P0/P1/P2 固定同一个 glmnet 风险预测，仅改变可靠性排序/筛选。
  P1 使用 glmnet 自身的 incident support diagnostics；默认方法清单不含
  abm_prevalent 时 P2 为 unavailable，不能静默混入历史模型。
  P1 阳性不等于 abm_count 获得验证。
- 保留现有协议：HTN 为 discovery；COPD 只有证明此前未查看结果才可作为
  replication candidate。AF 是跨 trait 检索后的 exploratory 候选，不能回填为
  预设验证终点；同一 UKB 的 prot / met 不构成外部人群验证。
  AF 原始 AURC 改善不等于同风险组成下可靠性改善，须保留风险标准化阴性比较。
- MI / AF 的 incident–prevalent 反向关联可作为描述性动机；当前 cohort 元数据
  未记录治疗协变量，不能解释为已证实机制、个体纵向翻转或保护作用改变。

### 后续分析边界

审查 C / D / E 属于后续分析选择，本轮未启动。新 count 验证应先限于 AF，保留原
冻结名单和参数；如需 Yang，显式指定 `glmnet,lightgbm,abm_count,abm_prevalent`。
运行前须依据实际 FINAL 索引、evaluation contract、MODEL_FROZEN 与 prepared source
完成复用校验，使用原 bootstrap、`--replace FALSE`，不绕过路径或参数失配 guard。
仅重算评估时使用既有独立评估入口。治疗敏感性须先核实真实基线药物变量与时间来源，
在单独目录运行 association-only；不得关闭药物来源 guard，也不得把已有
2/5/10 年 landmark 重新列为缺失分析。
