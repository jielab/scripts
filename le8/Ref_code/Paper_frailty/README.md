# Proteomics_frailty

These scripts were used in the paper: 
Jia et al. Plasma Proteomic Signature of Frailty in 50,506 Adults

1. Script for main proteome-wide association study (PWAS) analysis: 1_Proteome-wide association analysis.R
2. Script for pathway enrichment analysis and functional module identification:2_Pathway enrichment analysis and functional module identification.R
3. Script for organ-specific protein enrichment analysis: 3_Organ-specific protein enrichment analysis.R
4. Script for two-sample Mendelian randomization and colocalization analysis: 4_MR&Colocalization analysis.R
5. Script for development of the proteomic frailty score (PFS) model: 5_Development of PFS model.R
6. Script for calculating pairwise Jaccard indices for selected proteins across folds: 6_Calculate pairwise Jaccard index.R
7. Script for evaluating predictive performance for health-related outcomes: 7_Predictive performance for health-related outcomes.R
8. Script for iterative LASSO modeling by sequentially removing the strongest protein: 8_Iterative LASSO procedure.R
9. Script for recursive feature elimination (RFE) analysis based on SHAP values: 9_LASSO&SHAP-RFE.R
10. Script for longitudinal analysis: 10_Longitudinal analysis.R
11. Script for DESWAN analysis: 11_DESWAN.R
12. Script containing the function for calculating PFS in TwinGene: 12_Function used for calculating PFS in TwinGene.R
13. Script for evaluation of responses to modifiable risk factors: 13_Modifiable risk factors analyses.R
