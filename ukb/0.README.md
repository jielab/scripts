# ukb — usage notes

Run the public script with `-h` for minimal usage and an example with options. These examples are alternatives; complete workflows, prerequisites and detailed options follow.

## gen.sh — detailed reference

```text
cd /mnt/d/scripts/ukb

# GRCh37 -> GRCh38 imputed pfiles; then score against GRCh38 inputs.
./gen.sh liftGen --dir-in /mnt/f/gen/ukb/37/imp --dir-out /mnt/f/gen/ukb/38/imp \
  --chain-file /mnt/d/files/liftOver/hg19ToHg38.over.chain.gz
./gen.sh pgs --input /mnt/f/gwas/bmi.ref --label bmi \
  --dir-pgs-pfile /mnt/f/gen/ukb/38/imp --dir-out /mnt/d/analysis/ukb/pgs/bmi

# Independent SNP extraction from typed data; BED coordinates must match its build.
./gen.sh snp --dir-gen /mnt/f/gen/ukb/37 --data typ --snp-file /mnt/d/files/Wang_MY.bed \
  --snp-file-type bed --dir-out /mnt/d/analysis/ukb --label Wang

默认在前台执行。只有显式 --background 才将 pgs/snp/apoe 提交到 bsub。
```

## phe.sh — detailed reference

疾病日期核查可单独运行：`bash phe.sh date-check --Y cvd_afib`。
生成离线 `date-check.html`、全部患者/记录压缩表和汇总，比较 ICD、SRD、GP、
本地合并日期、UKB reference 及官方映射重建候选。完整定义、输入要求、
AOD 边界和受影响日期的重建步骤见 [DATE_CHECK.md](DATE_CHECK.md)。

SRD 提取名称为 `p20002 → srd.tab.gz`、`p20008 → srd.year.tab.gz`；
`--steps extract_multi --reextract-fields p20002,p20008 --run-r FALSE`
只重提并覆盖这两个字段。`extract_fod` 同时生成日期和来源文件，
包括 I48 的 `p131350/p131351`；来源字段不加入 `vip.lst`。

```text
cd /mnt/d/scripts/ukb

./phe.sh --start-step prep_raw --end-step process_linked --run-r FALSE
./phe.sh --start-step data_qc --end-step phe4gwas

# Optional ADuLT phenotype: requires complete population CIP (trait sex age cip source).
ADULT_ENABLE=TRUE ADULT_TRAITS=cvd_cad ADULT_CIP_FILE=/mnt/d/data/ukb/common/adu_cip.tsv \
  ./phe.sh --steps phe4gwas
```

PheWAS 表型准备统一使用 `f/phewas.R`（不拟合关联模型）。`roster` 核验原始参与者表、ICD10/日期导出及 RDS 是否一致，并结合退出名单生成人员覆盖名单；`rebuild` 根据该名单将 ICD10 映射为 phecode，应用对照排除和性别限制，输出 `PheWAS.rds`、日期、质控表及校验清单。

```bash
# roster 需要原始 UKB 导出以及 bash、gzip、cut，建议在 WSL/Linux 运行。
Rscript --vanilla f/phewas.R roster --dir-in /mnt/d/data/ukb --dir-out /mnt/d/analysis/bmonth/phewas
Rscript --vanilla f/phewas.R rebuild \
  --code /mnt/d/data/ukb/Rdata/icd10.code0.rds \
  --date /mnt/d/data/ukb/Rdata/icd10.date0.rds \
  --roster /mnt/d/analysis/bmonth/phewas/phewas_observable_roster.rds \
  --dir-out /mnt/d/analysis/bmonth/phewas
```

两个子命令均支持 `--help`；覆盖已有结果需要 `--replace`。R 中 `source("f/phewas.R")` 仅加载函数，不执行命令行流程；`phe.R` 的 `MAKE_PHEWAS=TRUE` 入口仍可使用。`rebuild` 需要 `data.table` 和 `PheWAS` 包。

PGS 的统一流程：先由 `gwas/format.sh pgs` 生成保留原生数值精度的总表，再转换为 RDS。LE8 不负责重新合并或修复评分精度。

可在 R 中手动转换（示例为 WSL 路径，Windows 下请使用对应盘符路径；转换 met 时替换输入、输出路径）：

```r
input <- "/mnt/f/gwas/prot/pgs/prot.pgs.gz"
output <- "/mnt/d/data/ukb/Rdata/prot.pgs.rds"
header <- names(data.table::fread(input, nrows = 0L, check.names = FALSE))
stopifnot(length(header) > 1L, header[1] %in% c("eid", "#IID", "IID"))
scores <- as.data.frame(data.table::fread(
  input, check.names = FALSE,
  colClasses = setNames("character", header[1])
))
names(scores)[1] <- "eid"
names(scores) <- sub("[.]SCORE_SUM$", ".pgs", names(scores), ignore.case = TRUE)
stopifnot(
  nrow(scores) > 0L, !anyDuplicated(names(scores)),
  !anyNA(scores$eid), !anyDuplicated(scores$eid),
  all(vapply(scores[-1], is.numeric, logical(1)))
)
dir.create(dirname(output), recursive = TRUE, showWarnings = FALSE)
saveRDS(scores, output, compress = "gzip")
stopifnot(identical(scores, readRDS(output)))
```

转换将首列按字符读取并命名为 `eid`、评分列后缀 `.SCORE_SUM` 改为 `.pgs`，不主动舍入或标准化评分。RDS 保存的是 `data.frame`。回读校验比较的是读入 R 后的数据与 RDS 回读结果，不保证原始文本数值超出 R 数值类型精度的部分。以上手动示例直接覆盖目标文件，不自动备份，也不检查转换期间源文件是否变化；如需保留旧 RDS，请先自行备份。
